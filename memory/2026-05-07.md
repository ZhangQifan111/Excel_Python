## GD32F527 USB Host FATFS 调试

### 项目结构
- MCU: GD32F527 (Cortex-M33, GigaDevice)
- RTOS: FreeRTOS
- USB: Host MSC (大容量存储)，接 Kingston DataTraveler 3.0 U盘
- FATFS: R0.15
- 日志: EasyLogger + SEGGER RTT

### 问题现象
- USB枚举成功，MSC枚举完成，FATFS f_mount成功
- 第一次 disk_read (读FAT引导扇区) 成功
- 第二次 disk_read (读sector 112384根目录) 失败 status=2 (USBH_FAIL)，10秒超时

### 根因
**USB BBB协议 Data Toggle 未重置**

`usbh_msc_bbb.c` 的 `BBB_RECEIVE_CSW_WAIT` 完成后只重置了状态机 (`bbb.state`, `bbb.cmd_state`)，
但没有重置 IN/OUT pipe 的 data toggle。导致第二次 SCSI READ(10) 的 DATA_IN 阶段，
host 端 toggle 和设备端不匹配 → host 控制器 NAK → URB 永远不完成 → 10秒超时。

### 修复
在 `usbh_msc_bbb.c` 的 `BBB_SEND_CBW` case 中，发送 CBW 前重置两个 pipe 的 data toggle：
```c
usbh_pipe_toggle_set(uhost->data, msc->pipe_out, 0U);
usbh_pipe_toggle_set(uhost->data, msc->pipe_in, 0U);
```
