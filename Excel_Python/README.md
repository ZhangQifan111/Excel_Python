## 项目概述
- **项目名称**: Excel 数据可视化工具
- **主程序**: `assets/excel_data_visualizer.py`
- **技术栈**: Python + Tkinter + Matplotlib + Pandas

## 工作清单

### 1. 新增功能：批量分析

#### 功能描述
- 支持批量分析多个 Excel 文件
- 自动识别符合命名规则的文件：`{设备编码}_BATTERY_REPORT` 或 `{设备编码}_REPORT`
- 用户可设置最多 3 条异常条件
- 支持导出分析结果

#### 异常条件类型
| 条件类型 | 说明 | 参数 |
|---------|------|------|
| 波动剧烈 | 数据偏离平均值超过阈值 | 阈值(%) |
| 超出范围 | 数据超出指定范围 | 最小值、最大值 |
| 缺失值过多 | 缺失值比例超过阈值 | 阈值(%) |
| 同增同减异常 | 两列数据变化方向不一致 | 列2选择 |

#### 使用方法
1. 选择包含 Excel 文件的文件夹
2. 点击"扫描文件"自动识别有效文件
3. 设置异常条件（最多 3 条）
4. 点击"开始批量分析"
5. 查看结果并导出

#### 代码位置
- 界面创建: `_create_batch_analysis_widgets()`
- 文件扫描: `scan_excel_files()`
- 批量分析: `run_batch_analysis()`
- 结果导出: `export_batch_results()`

### 2. Bug 修复

#### 1.1 点击图表显示数值与实际不符
- **问题描述**: 点击图表时显示的数值与实际数据不符（显示 47.00，但图表显示负值）
- **问题原因**: `dropna()` 后索引发生变化，但代码使用 `iloc[idx]` 访问时间列时没有考虑这个变化
- **解决方案**:
  - 使用 `valid_mask` 和 `loc` 获取有效数据和对应的时间值
  - 新增 `valid_data` 缓存结构，只存储非空数据
  - 改进多列选择时的综合距离计算逻辑
- **代码位置**: `generate_plot()` 函数中的数据缓存部分和 `on_plot_click()` 函数

#### 1.2 同增同减检测失效
- **问题描述**: 使用"同增同减"策略时，明明有数据不一致，但诊断结果显示正常
- **问题原因**:
  1. 两列数据分别 `dropna()` 后，行可能不再对应
  2. 没有正确处理值为 0 的情况（两个值都是 0 时，判断逻辑失效）
- **解决方案**:
  1. 使用 `valid_mask = df[col1].notna() & df[col2].notna()` 确保两列数据行对应
  2. 改进判断逻辑：
     - 两个变化量都为 0：跳过（没有变化）
     - 一个为 0 一个不为 0：视为异常（标记为"单侧变化"）
     - 符号不同（一正一负）：视为异常（标记为"方向相反"）
  3. 在诊断报告中显示异常类型
- **代码位置**: `run_correlation_diagnosis()` 函数

#### 1.3 波动剧烈检测的索引问题
- **问题描述**: 检测结果中时间与数据对应错误
- **问题原因**: `dropna()` 后索引发生变化
- **解决方案**: 使用 `valid_mask` 和 `loc` 确保索引正确对应
- **代码位置**: `run_volatility_diagnosis()` 函数

#### 1.4 数据范围异常配置界面最大值输入框被截断
- **问题描述**: "最大值"输入框在窗口较窄时看不到
- **问题原因**: 所有控件都在同一行水平排列，窗口宽度不够时右侧被截断
- **解决方案**: 将布局改成两行显示
  - 第一行：检测列选择
  - 第二行：最小值和最大值设置
- **代码位置**: `create_widgets()` 函数中的 `range_config` 部分

#### 1.5 数据范围异常检测列下拉框无内容
- **问题描述**: 切换到"数据范围异常"策略后，检测列下拉框为空
- **问题原因**: 修改布局后，`update_diagnosis_comboboxes()` 函数无法找到嵌套在 Frame 中的 Combobox
- **解决方案**: 修改遍历逻辑，递归查找嵌套在 Frame 中的 Combobox
- **代码位置**: `update_diagnosis_comboboxes()` 函数

#### 1.6 exe 版本启动时左侧面板不可见
- **问题描述**: exe 打包版本启动时左侧工具面板不可见，需要手动拖动分割条
- **问题原因**:
  1. 窗口初始尺寸 1600x1000 可能超出用户屏幕
  2. PanedWindow 分割条初始位置可能为 0
  3. 分割条位置设置延迟时间不够
- **解决方案**:
  1. 设置窗口最小尺寸 `minsize(1200, 700)`
  2. 窗口自动适应屏幕大小并居中显示
  3. 改进分割条初始化机制：延迟 100ms，最多重试 10 次
- **代码位置**: `__init__()` 函数和 `_init_sash_position()` 函数

#### 1.7 折线图显示不全
- **问题描述**: 部分数据超出 Y 轴范围被截断
- **问题原因**: 依赖 matplotlib 自动设置 Y 轴范围，有时不准确
- **解决方案**:
  - 自动计算所有选中列数据的实际最小值和最大值
  - 添加 5% 边距，确保数据不会贴边
  - 显式设置 Y 轴范围
- **代码位置**: `generate_plot()` 函数中 Y 轴范围设置部分

### 2. 功能说明

#### 偏差计算方式
```
偏差 = |当前值 - 平均值| / |平均值| × 100%
```
- 意义：表示当前值相对于平均值的偏离程度（百分比）
- 偏差越大，说明该点离平均值越远，越可能是异常点
